# v0.4 当前事实基线

更新时间：2026-09-10

## 已实现并验证

- 聚合工程包含 15 个 Maven 子模块，其中 `lms-common` 为公共库，其余 14 个为可运行服务；网关承担 JWT 校验和用户信息透传。
- 抢课成功事件由 `lms-course` 幂等落选课记录，并向 `lms-grab-landed` 发布 `recordId` 回执；`lms-grab` 仅允许记录从 `PENDING` 条件更新为 `LANDED`。
- 已用测试课程 8、库存 1 和真实学生账号完成一次运行态闭环：Redis 库存 `1 → 0`、`grab_record` 最终为 `LANDED`、`course_enrollment` 产生唯一有效记录，重复请求不新增数据，两个 Kafka 消费组 lag 均回落为 0。
- 对超过 5 分钟仍为 `PENDING` 的抢课记录执行 Kafka 幂等重投，不再在无法确认消费状态时盲目回补库存，避免“已回补后迟到落库”造成超卖。
- 教师快捷入口和通用个人 Agent 入口都绑定 JWT 角色，学生不能调用教师 Agent、创建教师会话或访问教师生成能力。
- AI Copilot 已支持 SSE 生命周期事件、停止响应、HITL 审批卡、会话任务树，以及桌面侧栏和移动端全屏布局。
- 17 份声明式 Agent 配置已加载：2 个个人 Agent 与 15 个领域/流程 Agent；邀请深度上限、工具策略、HITL 和 Trace 已启用。
- Python RAG 使用 Milvus、DashScope embedding 与真实生成模型完成一次隔离知识写入、检索问答、来源返回和清理闭环。
- 旧公共知识库向量由用户主动清除；23 个仍保留原文件的条目现标记为 `needs_reingest / vectors_missing`，`chunk_count` 返回 Milvus 当前真实计数 0，不会自动恢复旧索引。
- RAG 新上传和 CLI 入库必须携带正整数 `course_id`；RAGAS 采集按课程调用问答端，旧公共库数据集已归档且旧的无课程采集缓存不会复用。

## 必须如实描述的边界

- 当前 SSE 是“执行阶段事件 + 最终答案分片”，底层 AgentScope 调用仍是阻塞式完整返回，不是模型原生 token 流。
- RAG 对图片执行 OCR/VLM 描述并转成文本向量；当前生成器消费的是检索文本上下文，不是直接把图片送入多模态模型。
- ReMe 长期记忆、LLM 意图分类、会话自动摘要和 Kafka 任务通知默认关闭，不能写成已在线运行。
- 当前只有单学生、单库存课程的真实抢课闭环；一致性检查为 0 异常，但尚不能据此宣称抢课并发吞吐、P95 或零超卖容量结论。
- 历史 JMeter 报告测量的是课程读取接口，不是抢课或 AI 链路。

## 安全与配置

- API Key 只从运行环境读取，文档、脚本与报告不得记录真实值。
- JMeter JWT 必须由 `-Jtoken=...` 临时注入；仓库中的旧固定 Token 已移除。如该 Token 仍可能有效，应主动轮换。
